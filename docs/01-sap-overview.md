学员首次接触 SAP，能独立导航到常用事务码，浏览数据，建立对 SAP 体系的基本认知。

## Demo

## 知识点

### 1. SAP 系统架构概述
- 三层架构：表示层 → 应用层 → 数据库层
- 客户端（Client）概念与多租户

### 2. SAP GUI 布局与操作
- 菜单栏、标准工具栏、状态栏、命令栏输入事务码
- 会话管理（多窗口 /s）
- 快捷键（Enter = 执行，F3 = 返回，F12 = 取消）

### 3. 常用事务码
- SE38：ABAP Editor（编写程序）
- SE80：Object Navigator（对象浏览器）
- SE16：数据浏览器（查表数据）
- SE11：Data Dictionary（数据字典）
- SU01：用户管理

### 4. F1 帮助
- 光标放在字段上按 F1 查看字段文档
- F1 帮助中的"技术信息"查看表名和字段名

### 5. 查表技巧
- SE16N vs SE16 的区别（公司系统里两者都有；试用镜像只有 SE16）
- 通配符使用（* 和 +）
- 最大命中数设置
- 按字段排序和筛选

### 6. SE11 中查看表结构
- 表的字段列表、数据类型、长度描述
- 字段的 Check Table / Value Table
- 索引查看
- Where-Used List（使用清单）

### 7. SAP Easy Access 与用户菜单
- SAP 标准菜单树结构
- 收藏夹使用
- 用户自定义事务码

### 8. SAP 开发对象层级
- Development Class / Package 的概念
- 本地对象（$TMP）
- Transport Layer 与传输路径

## 💡 实战经验

- **事务码记不住怎么办？** 在 SAP 命令栏中输入 `/*` 开头，系统会弹出事务码搜索功能——比背事务码更高效
- **F1 是你最好的老师**：光标放在任何字段上按 F1，点"技术信息"可以直接跳到该字段所属的表和域名
- **SE16 的隐藏技巧**：在结果列表中双击某列标题，可以快速按该列排序——不需要每次都进排序设置
- **多窗口操作**：在命令栏输入 `/o` + 事务码（如 `/oSE38`），可以在新窗口打开，方便同时看代码和数据
