## 知识点

### 1. 断点类型
- 静态断点：代码中写 BREAK-POINT / BREAK 用户名
- 动态断点：在调试器界面设置
- 外部断点：外部系统调用时触发
- 语句断点：在特定 ABAP 语句处暂停

### 2. 调试器界面布局
- 代码窗口、变量窗口、结构体窗口、调用栈(Call Stack)、断点Tab

### 3. 常用快捷键
- F5 (Step Into)：进入子程序/Function/Method 内部
- F6 (Step Over)：执行当前行，不进入子程序
- F7 (Step Return)：返回上一层调用者
- F8 (Continue)：运行到下一个断点

### 4. 变量查看
- 双击变量查看值
- 查看内表内容（展开 Table）
- 查看结构体字段

### 5. Watchpoint（观察点）
- 设置条件：当字段变为指定值时暂停
- 实际场景：调试 LOOP 内的条件判断

### 6. 其他调试技巧
- Fields 工具栏：查看系统变量（SY-SUBRC / SY-DBCNT 等）
- 调试时修改变量值（Field Contents → Change）
- 跳转到指定行（Goto Statement）
- 查看数据库执行结果（Database Table）

## 💡 实战经验

- **最常用的调试方式**：90%的情况只需要 F6（Step Over）和查看内表内容。不要一上来就用 F5（Step Into）钻进系统 Function 里去——你会迷路的
- **Watchpoint 是调试 LOOP 的利器**：比如想看"循环到哪一次时 sy-subrc 变成了非 0"——在 sy-subrc 上设一个 Watchpoint（条件：<> 0），程序会自动在那一轮暂停
- **调试时修改数据**：在调试器中双击变量 → 改值，可以"伪造"程序状态来测试后续逻辑。比如把某个 IF 条件的变量改为 0，看 ELSE 分支是否正确
- **外部断点**：在 SE37 中调试 Function 时，要用"外部断点"（在调试器中点 Settings → External Breakpoint），否则从外部调用时断点不会触发
- **不要在生产环境随便设断点**：BREAK-POINT 会暂停所有用户的程序执行！测试环境可以随便调试，生产环境务必谨慎
